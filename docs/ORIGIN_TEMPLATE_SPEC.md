# Origin Template Spec — 前人 Pt L3 XAFS 套图风格规范（2026-08-18 提取）

> 来源：`data/raw/Figure/*.wmf`（前人 Origin 导出的本课题 XAFS 图件，
> 7 张经 Inkscape 转换 + 视觉分析交叉验证）。复刻实现见 recipe
> `origin_template_mimic.py`。本规范用于"客户要跟组里/前人风格一致"的订单。

## 曲线编码（最强特征）

| 元素 | 规格 |
|---|---|
| 数据曲线 | **蓝 #1F77B4**，实线，1.5–2 pt |
| 拟合曲线 | **红 #D62728**，实线同宽（R/K 空间拟合图标准配对） |
| XANES 叠图 | 单蓝主线（多标样叠图时蓝为主，其余色未强约定） |

## 版式

- 坐标框：**四边框 + 内向刻度**（拟合图）；XANES 图为开放框（仅左/下轴）
- 轴题（照抄文本）：`Energy (eV)` × `Normalized μ(E)`；`R (Å)` ×
  `|χ(R)| Fourier Transform Magnitude`；k 空间 `k³χ(k)` 族
- 图例/标注：拟合图带注记框（CN/R/σ² 类），位置无强约定
- 小波图：**jet/rainbow 色图 + 右侧竖直 colorbar**（前人风格；
  与本仓库色彩纪律冲突——复刻时给 jet 版 + viridis 建议版双方案）

## 与本仓库投稿纪律的融合决策

前人模板字体混用（XANES 图无衬线、拟合图 Times 衬线观感）；复刻统一
**Arial**（投稿技术审查安全）。其余视觉要素 1:1 保留——客户辨识度来自
蓝/红配对与轴题措辞，字体统一不影响"像前人风格"的观感判定。
