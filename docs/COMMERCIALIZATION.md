# Commercialization — 商业化路线图

> 2026-08-17。定位：**纳米材料 / 生物 / 艺术设计**三垂直领域的
> 投稿级图件流水线。核心命题：卖的不是"画图"，是"**过审保障**"。

## 一、差异化护城河（按防御强度排序）

1. **figcheck 审计**（GAP G2 空白已确认）：页内性/字体/负号/字号实测/
   裁切风险——"图未过检，稿不出门"。通用 AI 绘图工具（含 ChatGPT 直出）
   均不提供；这是唯一可专利化叙事（工作流+规则集）的资产
2. **数值一致性校验**：图上注记与数据文件对账（科研人最痛的翻车点）
3. **最终坐标系纪律**：mm 级交付物（期刊技术审查直接过）
4. **三领域模板深度**（成长性结构支撑，随使用单调变强）
5. 多软件工具链（Origin/MATLAB/COMSOL/Inkscape CLI）——竞争者做不了
   的取数能力

## 二点五、竞品格局实证（2026-08-17 搜索调研，定价待进一步核验）

**国内付费科研绘图网站全部是"示意图拖拽"类，无一做"数据图+过审审计"**：

| 竞品 | 类型 | 定价 | 与我们的关系 |
|---|---|---|---|
| 科研者之家 Figdraw 2.0 | BioRender 类拖拽，6000+ 论文引用 | 年 ~299 元，高校机构版常见 | 互补：它做"画"，我们做"数据图+过审" |
| MedPeer | 示意图+素材库 | 绘图会员 720 元/年 | 互补；其定价是我们的订阅锚 |
| 杉图里 | BioRender 平替 | 低价 | 互补 |
| BioRender（国际） | 生物示意标杆 | $19–39/月 | 心智与价格上限锚 |
| 人工高端绘图（3D/封面） | 服务 | **单张 ≥500 元**（科学网促销立减 500 元反推原价更高） | 我们 3D 路线（G9）的目标区间 |

**结论**：①"数据图 + figcheck 过审报告"定位在付费网站中没有直接竞品；
②三领域里"生物示意图"是红海（Figdraw/MedPeer/BioRender 混战），
我们的生物主打应是**统计图 + 数值一致性**而非示意图；
③3D（晶体/封面）是高价空白，学习路线 P1-P2 见 `CHART_CATALOG.md`。

## 四、打法（与既有烟雾测试结论衔接）

### 阶段 0（本周，成本≈0）：上架开源
- 仓库已建；提交进 awesome-claude-skills / 社区 skill 注册表
- README 挂 figcheck 预告（waitlist 邮箱收集）

### 阶段 1（2 周，服务烟雾测试）：先卖服务，不写网站
- 淘宝/闲鱼/小红书挂"期刊级 figure 重绘 + figcheck 过检报告
  49–99 元，24h"
- **每单记录**：领域、图型、agent token 成本（实测 1-10 元/单）、
  返工次数、客户"为什么不直接问 ChatGPT"的回答
- **证伪条件**：两周 <10 单或毛利 <50% → 判定付费意愿不存在，只保留
  开源仓库作为个人影响力资产，停止投入

### 阶段 2（4-6 周，仅在阶段 1 通过后）：figcheck CLI
- PyPI 发布；基础四查免费，期刊规则集（Nature/IEEE/各刊字号线宽
  规范库）+ 批量模式付费
- 同步做 G7 基准（20 数据集三跑对比）作发布营销素材

### 阶段 3（3 个月+）：web 服务
- 参数面板 + 重渲染循环（G4 v1）；三领域模板菜单（G5）
- 收费：单图 9.9-49 / 月订阅 99-299（锚 BioRender）

## 五、单位经济（待实测校准）

- 单图 agent 成本：token 1-10 元 + 视觉模型审图 0.5-2 元
  （G8 确定性检测落地后可再降）
- 人工介入率（阶段 1 实测目标 <30%）：决定阶段 3 能否盈利
- 定价安全边际：49 元定价下毛利 >80%（阶段 1 验证）

## 六、风险与诚实边界

- **低频硬伤**：博士生年发文 1-3 篇 → LTV 薄，商业模式必须靠
  多领域横向扩展（三领域定位正是对策）+ 服务纵深（审稿返工陪伴）
- **可证伪替代解释**：客户付钱买的可能是"代工拖延症"而非 AI 能力——
  阶段 1 访谈必须回答此问，答案决定 L2/L3 是卖工具还是卖服务
- **GPT 免费及格线持续抬升**：护城河必须钉在"校验与保障"层，
  不在"生成"层（生成会持续贬值，校验不会）
- **数据合规**：纳米材料未发表数据保密是刚性需求 → 本地/私有部署
  版本可作为机构级产品线（院系/课题组买断）

## 七、与主资源的关系

本路线为副线现金流实验，阶段 1 有硬止损线（两周/<10 单），不与主线
争夺注意力；阶段 2+ 的启动以阶段 1 数据为准，不预支投入。
